# Operations Playbook

Use this skill as one entrypoint for repeatable operational procedures: choose
SOP, runbook, RACI or process-map mode from the request and scope.

## Workflow

1. Define trigger, outcome, owner, actors, prerequisites and explicit exclusions.
2. Map normal path, approvals, evidence, observability, failure states and stop rules.
3. Add least-privilege roles, reversible steps, rollback, recovery and escalation.
4. Write verification and acceptance criteria that another operator can execute.
5. Review for ambiguity, unsafe defaults, missing ownership and stale dependencies.
6. Deliver a draft or review record. Production execution, credentials, destructive
   actions and external communication require explicit approval at the step.
